# VmusiC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: execute task-by-task (checkboxes).
> **Spec:** `docs/superpowers/specs/2026-10-10-vmusic-design.md`

**Goal:** Produce `/root/VmusiC-new` — a renamed, Discord-free, dark Spotify-ish fork of Metrolist that builds on GitHub Actions.

**Architecture:** Mechanical rename of app-owned namespaces + package dir moves, targeted removal of the Discord subsystem, small global theme/shape change, icon and README/docs work, CI runner/env updates. Verification is static (no local Android SDK); APK build verified in Actions.

**Tech Stack:** Kotlin, Jetpack Compose, Material3, Hilt, Room, Gradle/AGP, GitHub Actions.

## Global Constraints
- New app package `com.vmusic.music`; innertube package `com.vmusic.innertube`.
- Never rename: `com.metrolist.innertubex|shazamkit|kugou|lastfm|paxsenix|lrclib`, `com.github.MetrolistGroup.*`, `MetrolistGroup`.
- Do not bump `versionCode`/`versionName`.
- No leftover `com.vmusic.music`, `com.vmusic.innertube`, or Discord references.

## Review Focus
- A leftover `com.vmusic.music`/`innertube` reference breaks compilation.
- Over-broad rename corrupting external `com.vmusic.*` deps breaks compilation.
- Discord removal leaving a dangling import/route/manifest entry breaks build or runtime.
- `metrolist_strings.xml` rename missing a locale or a reference.
- CI env/runner mismatch makes the workflow fail on a fresh repo.
